Inventory Management System

A full-stack inventory management application designed to help users efficiently manage products, suppliers, and inventory transactions. TaskOps Ticketing System

TaskOps is a task management application designed to help users organize, track, and manage their tasks efficiently. It provides a simple and intuitive interface for creating, updating, and managing tasks while keeping important information organized in one place. Built using React, TypeScript, Node.js, Express, and REST APIs, the project was developed in an Agile environment using sprints to plan, develop, test, and improve features incrementally. This project strengthened my experience with full-stack development, CRUD operations, teamwork, and Agile software development practices.

JobTrack is a full-stack job search management application designed to help job seekers organize and manage their job search in one place. Users can save job opportunities, track applications through Prospect, Applied, and Interview stages, manage important deadlines and events through a calendar, maintain personal notes, and view analytics about their job search activity. Built with Next.js and TypeScript, JobTrack provides a centralized and intuitive way to stay organized throughout the job application process.
